## Results categories

Results has five tabs: Spatial Reach, Angled Reach, Hardware Runs, Visual Robustness, and Angled Lift. Each owns a separate carousel track, initially showing “Coming soon.” Replace each `.carousel-empty` with `.teaser-slide` video figures when adding results. The shared carousel handles arrows, touch scrolling, keyboard navigation, and visibility-aware playback.
